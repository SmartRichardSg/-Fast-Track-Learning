Fast Track Method

1. Start with the minimum.
Choose the smallest useful goal. Make it achievable, not perfect.
2. Break it down and see the whole.
Divide the subject into manageable chunks, then note how the parts connect.
3. Remember, explain, apply.
Recall without looking, explain in simple words, then practise using the knowledge.

Extra suggestion: End each practice session by writing one thing you learned, one thing to improve, and the next small action. Revisit it the next day to check what you still remember.
